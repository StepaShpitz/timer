# Тактика на клетках

Пошаговая тактическая игра в браузере: случайные карты, туман войны, местность даёт способности, случайные цели миссий.

Сейчас это один файл `index.html` без сборки и зависимостей. Публикуется через GitHub Pages на домен из `CNAME`.

## Ресурсы и лицензии
- Иконки: [game-icons.net](https://game-icons.net) — Delapouite, Lorc, Sbed, Willdabeast (CC BY 3.0).
- Текстура равнины: набор «Backgrounds and Textures» by Morain (morain.itch.io), встроена в игру; сам набор в репозиторий не выкладывается.
- Шрифт: Barlow (Google Fonts).
